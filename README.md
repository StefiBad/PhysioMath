# Math & Physics Sandbox

Un entorno interactivo experimental basado en la web para explorar sistemas dinámicos, geometría fractal, procesamiento de señales y autómatas celulares en tiempo real utilizando HTML5 Canvas y JavaScript nativo.

## Módulos Incluidos

* **Péndulo Doble:** Simulación de un sistema dinámico acoplado no lineal que exhibe comportamiento caótico determinista. Muestra trayectorias divergentes basadas en la energía cinética.
* **Caja de Gravedad:** Simulación cinemática de partículas en un entorno cerrado con colisiones elásticas, conservación del momento lineal y fricción ajustable.
* **Fractales (Julia):** Renderizado interactivo en el plano complejo de conjuntos de Julia con soporte para paneo y zoom infinito.
* **Análisis de Fourier:** Demostración geométrica de series armónicas mediante epiciclos circulares que modelan una onda compleja.
* **Juego de la Vida:** El clásico autómata celular de Conway gobernado por leyes de densidad biológica, con interacción directa para sembrar células muertas o vivas.
